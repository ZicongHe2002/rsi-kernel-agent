## 启动

Windows 双击 **启动知识库.cmd**，浏览器会打开 http://127.0.0.1:8765 ，并通过本机生成的一次性入口登录 owner「风落」（ID `fl`）。再次双击会打开已经运行的站点并恢复 owner 登录。仅在自己的电脑上运行此启动器，不要把 owner 登录链接发给其他人。

后台服务运行期间可以关闭浏览器，之后重新打开地址即可。双击 **停止知识库.cmd** 关闭后台服务。

需要 Python 3.10 或以上。启动器优先使用这台电脑现有的 Colab CLI Python 环境，否则检查 PATH 中的 Python 和 `py` 启动器。其他电脑需自行安装 Python。

也可以从终端启动：

```sh
python server.py --port 8765
```

端口被占用时，可用 `python launch.py --port 8766`，对应使用 `python stop.py --port 8766` 停止。添加 `--no-browser` 可只启动服务，不打开浏览器。`launch.py` 使用当前 Python 环境启动后台服务；直接运行 `server.py` 时按 Ctrl+C 停止。

## 账号与访问权限

授权类型可选择「全部文档」，涵盖当前及以后新增的文档；仍可选择「可阅读」或「可编辑」。这不会授予管理账号、删除、回收站或其他 owner 权限。

owner 固定为「风落」，ID 为 `fl`，可以阅读、修改和管理全部文档。页面上的「账号与权限」可创建普通账号，分配分类或单篇文档的阅读、编辑权限，并处理新浏览器的访问申请。没有授予权限的文档不会出现在该账号的列表、搜索和正文接口中。

同事只需输入你创建的 ID，不需要密码；第一次使用某个浏览器时，页面会显示访问申请，需由 owner 确认批准后才可进入。**只输入 `fl` 不会得到 owner 权限**。已批准的浏览器会记住身份；更换浏览器、清除网站数据或退出后，需要重新申请。你可停用账号来撤销访问。

分类权限适用于该分类及其子分类；阅读权限允许查看和导出，编辑权限包含阅读，并允许修改对应文档的正文与待办。成员在具有编辑权限的分类中还可新建文档；仅获单篇文档编辑权限时，不能据此新建同分类的其他文档。各项授权取并集，单篇只读授权不会抵消分类编辑授权。

重命名、移动、删除文档，访问与恢复回收站，以及管理分类，都仅限 owner。成员编辑现有文档时，标题和分类不可修改。文档授权按路径匹配，owner 重命名或移动文档后需核对原授权；例如单篇文档授权不会自动跟随到新路径。

owner 在本机通过启动器登录。如果浏览器未能自动打开，也可以从 `knowledge-site` 目录运行：

```sh
python owner_admin.py bootstrap --open
```

省略 `--open` 会在本机终端输出一次性登录链接，有效期 10 分钟，使用一次即失效；生成新链接会撤销上一条尚未使用的链接。链接的 token 放在 URL fragment 中，不进入网站 HTTP 访问日志。`--port 8766` 可指定其他端口。不要把链接复制到聊天、日志或共享文档中。

## 让不同网络的同事访问

`http://127.0.0.1:8765` 只对这台电脑有效，不能作为同事的访问地址。账号与权限启用后，还需 HTTPS 公网隧道或反向代理，把一个公网地址连接到本机服务。电脑、知识库服务和隧道需要保持运行；隧道停止后，公网地址将无法访问。

网站分享与现有的 ChatGPT MCP Tunnel 是两个连接。`连接ChatGPT.cmd` 只连接 ChatGPT 的 MCP 功能，不会自动发布网页。请使用网站的 HTTPS 分享入口或已有 HTTPS 代理；同事收到的是普通网站地址，不包含 owner token。只有完成公网连接并在其他网络验证访问后，才算已经上线。

Windows 双击 **分享知识库.cmd**，会先启动本机网站，再使用附带的官方 `cloudflared` 工具申请免费的 Cloudflare Quick Tunnel 临时 HTTPS 地址。窗口出现 `Share URL: https://….trycloudflare.com` 后，把这个普通网址发给同事即可。此模式无需 Cloudflare 账号或付费订阅，重新启动分享会换一个网址，适合先试用；固定域名和长期运行需另行配置。

保留分享窗口，按 Ctrl+C 可以停止分享，本机网站继续运行。若分享在后台运行，从该目录执行 `分享知识库.cmd stop`，或运行 `python share.py stop`；停止命令只通知本网站的分享进程退出，不按 PID 终止其他程序。命令行 `python share.py --port 8766` 可指定本机网站端口。一个知识库同时只允许启动一条此类分享连接。

分享日志位于 `logs/share-cloudflared.log`。临时网址写入 `.auth/public-origin.json`，网站仅接受已配置的网址；正常停止时会移除本次网址。此地址是同事登录入口，所有文档读取和修改仍需账号权限。隧道进程未连接成功时，即使已经分配了地址也可能暂时无法打开；以浏览器实际连通为准。

## 文档在哪里

`content` 是知识库，文件夹是分类，文件名是文档标题：

```text
content/
  学习方法/
    rsi-document-index.md
    rsi-kernel-agent.md
    rsi-memory.md / rsi-knowledge-search.md
    rsi-optimization-workflow.md / rsi-benchmark.md / rsi-profiler.md
    rsi-evidence-contract.md
    RSI实践/
      rsi-multi-plan-exploration.md
      rsi-profiler-analyzer.md
      rsi-phase2-roadmap.md
      rsi-method-search-and-selection.md  # 旧入口迁移说明
  归档/已合并/
  待办清单/
  .trash/                               # owner 回收站
```

当前文档入口见[RSI 文档索引](content/学习方法/rsi-document-index.md)，仓库层审计、来源清单和权限说明见[工程索引](index.md)。最初四篇使用示例目前位于回收站，不是当前设计资料。

- 在有分类编辑权限时，点击「新建文档」后填写标题、分类和 Markdown 正文，再保存。
- 分类支持 `机器学习/TPU` 这样的多级名称；owner 编辑文档的分类即可移动文档。
- 「导入 Markdown」把文件放进编辑器，点击保存后才写入知识库。
- 把已有 UTF-8 `.md` 文件直接放入 `content`，刷新页面也能读取。UTF-8 BOM 可读取；其他编码需先转换。
- 点击「导出」下载当前文档的原始 Markdown。
- 正文中的文档链接会在网站内直接切换，例如 `[下一篇](下一篇.md)`、`[跨分类](../机器学习/TPU笔记.md)`；支持中文、空格和 `文档.md#小节标题`。浏览器地址包含当前文档，刷新、后退或复制这个本机链接都可再次打开；外部网站链接仍在新标签页打开。
- owner 在阅读页点击「删除」，文档会移入左侧「已删除」，保留原文和原分类。此回收站仅 owner 可访问，可搜索、只读查看并点击「恢复文档」。原位置已有同名文件时会提示处理冲突，不覆盖现有文档。当前不提供永久删除。
- 备份整个 `content` 文件夹即可保留所有文档和分类。此版本不管理图片附件；正文可显示 HTTPS 图片。
- 已删除文档保存在 `content/.trash`，备份时也应包含此隐藏目录。直接在文件管理器删除的文件不会进入网站回收站。
- 当前版本用文件名管理标题，不解析 YAML frontmatter 元数据。

## 编辑说明

有文档编辑权限时，点击「编辑文档」后，可以选择分屏预览、Markdown 或阅读预览。窄屏下选择「阅读预览」查看渲染结果。只有阅读权限的成员不能修改正文或勾选待办。

顶部「收起列表」可隐藏中间的文档列表，让正文使用更多空间；点击「展开列表」可恢复。浏览器会记住这个状态，刷新后保留。点击分类或按 `/` 搜索时会展开列表。

owner 打开网站时会按北京时间（Asia/Shanghai）准备本周清单，周一作为一周的开始；点击左侧「本周待办」直接打开它，同一周不会重复创建。新的一周 owner 首次打开网站、回到网页或页面保持打开并检测到日期变化时，会准备新周清单。旧周文档保留；新周准备时会从最近的历史周清单提取未完成事项，去重后结转，并记录已处理标记，避免重复搬入。网站关闭期间无需后台运行，也不会补建未使用过的空白周。现行新周模板包含「本周待办」和「完成记录」，不再按周一至周日分栏。

「本周待办」和「长期待办」快捷入口及自动创建操作仅限 owner；清单创建后，成员可在文档列表中按获得的阅读或编辑权限使用它们。

「长期待办」是一份不限日期的固定清单，适合记录以后再做的事项，不随周变化重置。两种清单都可以点击小节下的「＋ 添加待办」，生成一行「复选框＋文字输入」；直接填写事项，按 Enter 或点击别处自动保存，不用填写 Markdown，也不用切换编辑模式。左侧方框可以完成或取消任务，刷新或重新打开后保留，并显示完成数量。保存失败会撤回本次勾选；其他窗口或 GPT 已更新正文时会提示重新打开，避免覆盖新内容。

已删除的本周或长期清单不会自动重新创建；owner 点击相应入口会打开它的只读回收站版本，可点击「恢复文档」继续使用。删除一份清单不影响另一份或后续新周的创建。

普通文档也支持标准 Markdown 待办：`- [ ] 待办事项` 和 `- [x] 已完成事项`。编辑器中点击「＋ 插入待办」可插入一项，选中多行时可把每行转换成待办。编辑预览中的勾选会同步修改 Markdown 和本机草稿，需点击「保存文档」才正式写入知识库。代码块里的待办示例保持原样。

阅读模式中，点击已有待办文字即可在同一行修改，按 Enter 或点击别处自动保存，Esc 放弃本次修改；子任务及其他正文保留。连续点击列表下方的「＋」会先保存当前事项，再生成下一条空白行。空行不保存。顶部「＋ 新增待办」也可添加事项。待办清单直接以可操作的行显示；普通知识文档仍有「就地编辑正文」与「编辑文档」。未保存的修改保留为本机草稿，刷新后可从「本机草稿」恢复。发生版本冲突时保留输入，不覆盖其他窗口或 GPT 的更新。

新周模板包含 `## 完成记录` 区。带此标题的文档在勾选任务时会自动追加完成时间与任务文字；取消勾选则追加「重新打开」记录，保留过程。编辑预览中的记录与勾选一起在保存文档后生效。普通文档没有这个区时，仅更新复选框。记录基于页面操作及明确告知的进展，不自动推断电脑外的工作。

支持 Mermaid 图表：在以 `mermaid` 为语言名的围栏代码块中写流程图、时序图等，阅读页和编辑预览会自动显示图形。支持中文标签与 `classDef` 配色；图表可点击「放大图表」查看原尺寸，也可展开源码。语法错误时保留源码并提示，不影响其他正文。Mermaid 渲染库随网站保存在本地，无需访问外部 CDN。保存和导出仍保留原始 Markdown。

图表按类型加载，滚动时暂缓启动下一张图；组件下载失败可点击「重试加载图表」，无需重载页面。文档切换会复用当前会话中最近读取或预读的正文，并在后台核对最新版本；编辑中的内容不会被后台结果覆盖。正文缓存仅保存在内存，最多 8 篇、2 MiB、30 秒，退出、权限变化或保存时失效。省流量模式和 2G 网络下不会自动预读相邻文档。

- `Ctrl+S` / `⌘+S`：保存。
- `/`：聚焦搜索框。
- `N`：新建文档（未聚焦输入框时）。

点击「保存文档」或按 Ctrl+S 后，正文写入 `.md` 文件；关闭浏览器、重新启动网站后仍会保留。

编辑时同时保留**本机草稿**。刷新或重新打开同一个浏览器后，点击「本机草稿」或顶部草稿提示即可恢复。草稿按知识库和编辑会话分别存储；恢复后仍需点击保存。草稿不自动同步给同事或其他设备，清除浏览器数据也会清除草稿。浏览器存储不可用时，编辑器底部会提示，需及时保存文档或复制正文。

同一文档在另一窗口保存后，旧窗口再次保存会提示冲突并保留编辑器里的正文。先复制保留当前修改，再重新打开最新文档处理；不会自动合并。

## 本机运行与维护

服务只监听 `127.0.0.1`，本机可直接访问，跨网络访问由 HTTPS 隧道或反向代理接入。网页编辑保存到真实 `.md` 文件，默认不扫描工作区其他目录。所有前端依赖已随网站保存，本机常规使用无需联网。

账号、授权、浏览器会话及本机工具凭据保存在 `.auth`，不通过网站文档接口提供；文档备份只包含 `content`；认证状态的备份/迁移必须另行批准并使用本机安全存储，不能复制到文档、清单或报告。本轮未读取、复制、移动或改变 `.auth`。此位置与新的文档区安全边界不一致，迁移方案见[认证状态迁移提案](access/AUTH_STATE_MIGRATION_PLAN.md)，本阶段仍未实施。原有本机 stdio MCP 连接仍属于 owner，普通网页成员的权限不会自动应用到该连接。

默认端口的服务日志位于 `logs/server-8765.log` 和 `logs/server-8765-error.log`。启动器记录对应服务的进程与关闭凭据，只能停止自己启动且核验匹配的服务，不会终止占用端口的其他程序。后端为 Python 标准库，前端使用本地附带的 Marked 和 DOMPurify，版本、来源及校验值见 `web/vendor/VERSIONS.json`，许可证随附。

测试：

```sh
python -B -m unittest discover -v
```

从 `knowledge-site/` 运行完整单元/HTTP 测试发现命令；测试会创建临时文件和本地 HTTP 服务，不是只读操作。浏览器 QA 另见 `qa/`。2026-11-11 本次只验证文档、语法、链接、哈希及公式自洽性，没有执行这些测试，也没有 TPU 验证。

## 让网页版 ChatGPT 读写知识库

可选的 MCP 连接提供搜索、Markdown 正文读取、新建文档和编辑文档，也可修改标题与分类，使用 OpenAI Secure MCP Tunnel 接入。首次设置见 [CHATGPT_SETUP.md](CHATGPT_SETUP.md)，之后双击 `连接ChatGPT.cmd`；启动连接时也会启动本地网站。写入通过网站保存接口检查版本，避免覆盖网页刚保存的修改。GPT 保存后刷新网页即可查看。本地网站无需此连接也可正常使用。
